E-Commerce Sales & Profit Analysis Dashboard

Objective:To analyze sales performance, profitability, and regional trends using Excel, and provide actionable insights to support business decision-making.

Tools & Techniques Used:
Microsoft Excel
Pivot Tables & Pivot Charts
Data Cleaning & Transformation
Dashboard Design (Slicers, KPIs) 

Dataset:The dataset contains transactional sales data including:
-Product Category
-Region
-Sales Revenue
-Profit
-Order Date

Key Features:
Interactive dashboard with slicers for dynamic filtering
Sales and profit analysis by category and region
Time-based trend analysis
KPI tracking (Total Sales, Total Profit, Total quantity)

Key Insights:
Identified top-performing product categories contributing maximum revenue
Analyzed profit margin variations across regions
Highlighted underperforming areas for potential improvement
Observed seasonal trends in sales performance

Project Highlights: This project demonstrates the ability to transform raw data into meaningful insights using Excel, along with strong skills in data analysis, visualization, and business storytelling.

How to Use:
Open dashboard.xlsx
Use slicers to filter data
Analyze key KPIs and trends from the dashboard.
